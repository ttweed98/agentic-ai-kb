**Teaching already given on this page (don't repeat, build on it):**
- The 802.1X analogy: client = supplicant, **MCP server = the switch** (blocks and points the
  way), **authorization server = RADIUS/ISE** (Keycloak here).
- The six steps: 401 + `WWW-Authenticate: Bearer ... resource_metadata=` → read Protected
  Resource Metadata at `/.well-known/oauth-protected-resource` (resource, authorization_servers,
  scopes_supported) → authorization-server metadata (OIDC / RFC 8414) → registration
  (pre-registered or **DCR**) → browser login, OAuth 2.1 auth code **+ PKCE** → every request
  carries `Authorization: Bearer`.
- **Audience** = who the token is for; reject tokens meant for another API (stops token
  passthrough). Fixed audience is test-only; production derives it from the client's `resource`.
- **Scopes** = least privilege; `mcp:tools` is a catch-all, split per tool where possible.
- **stdio servers skip all of this** — environment credentials instead.
- ⚠ Read-with-care: the page's last pitfall mentions `Mcp-Session-Id`; 2026-07-28 Streamable
  HTTP went stateless per earlier notes — check the 2026-07-28 transports page before trusting it.

## 2. What was learned this stretch (2026-10-05 → 10-08)

### MCP — from the Anthropic course (`~/MCPA/anthropic-mcp-course/cli_project`, NUC)
- Built a document server with **tools** (`read_doc_contents`, `edit_document`), **resources**
  (all doc IDs; one doc's contents), and **prompts** (`format`, summarize). This closes the known
  hole *"he has built tools only"* — resources and prompts are now built once, on the 1.x SDK.
- **Who controls what** — tools: the model · prompts: the user · resources: the application. He
  has this cold.
- **In the course CLI:** `/` lists **prompts** (user picks them = slash commands); `@` lists
  **resources** (app surfaces them). He first said `/` = resources; corrected.
- **Direct resource vs template:** both use `@mcp.resource`. The **`{placeholder}` in the URI**
  makes it a template (`docs://documents/{doc_id}`). Listed by `resources/list` (direct) and
  `resources/templates/list` (templates). ⚠ He first answered "the decorator makes it a template"
  — corrected; worth one more check later.
- Prompts return a list of messages: `return [base.UserMessage(prompt)]`, which needs
  `from mcp.server.fastmcp.prompts import base`.
- The course pins **`mcp` 1.26.0 → speaks 2025-11-25**, so the Inspector shows **LEGACY**, and its UI
  differs from the course video (older Inspector). 2.x tracks 2026-07-28.
- Tool errors: `raise ValueError(...)` comes back to the model as a tool result with `isError`, not
  a JSON-RPC protocol error.
- Design note he should keep: `edit_document` silently does nothing when `old_str` isn't found.
  A good tool tells the model it failed.
